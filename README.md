Obsidian Math Plotly 插件技术规范与操作指南

本程序系专为 Obsidian 环境开发的高性能扩展组件，旨在通过结构化代码块实现数学函数图表的集成化渲染。该系统的核心架构基于 Math.js 解析引擎与 Plotly.js 绘图库，用以提供精确且具备交互性质的图形表征。

系统核心职能

多维绘图能力：该组件支持涵盖二维及三维欧几里得空间函数、极坐标系统、柱面坐标系统、球面坐标系统、隐函数、参数化方程以及向量场定义之图形化呈现。

参数动态交互：通过 parameter 指令之定义，可在界面中生成滑块控制元件，进而实现函数图像随参数演变之实时动态监测及动画录制。

移动终端自适应优化：程序内建屏幕视口宽度检测机制。若终端设备之物理宽度低于预设阈值，图表容器之宽度将自动调整至最大化状态，以确保视觉呈现之完整性。

数据分析视图切换：提供图表表征与离散数据表格之间的一键式模态切换职能，便于对计算所得之数值结果进行高精度稽核。

高级定制化配置：用户被赋予对色彩方案、线段宽度、图形主题、定义域范围及采样频率（渲染质量）等参数进行全局或局部修改之权限。

暗色模式兼容性：系统默认采用与 Obsidian 原生暗色主题高度协同之配色策略，并支持针对图表元素进行动态色域调整。

部署流程

须在 Obsidian 插件根目录（即 .obsidian/plugins/）内建立名为 obsidian-math-plotly 的专属目录。

须将下列核心文件完整分发至上述目录内：

main.js (执行逻辑)

manifest.json (元数据定义)

styles.css (样式表)

math.min.js (解析依赖)

plotly.min.js (绘图依赖)

须在 Obsidian 系统设置界面中激活 Math Plotly 插件。

算例演示

在 Markdown 文档中，须利用 plot 代码块执行如下指令：

1. 二维显式函数呈现

y = sin(x) * cos(x/2), color=#ff7f5e, linewidth=4
range=[-10, 10], title=数学解析图像


2. 含参数滑块动态演化

param=[a, 1, 10, 0.1]
y = sin(a * x) / x
range=[-10, 10], color=#4cc9f0


3. 三维曲面生成

z = sin(sqrt(x^2 + y^2)) / sqrt(x^2 + y^2)
range=[-8, 8], samples=50


4. 三维空间参数方程

[cos(t), sin(t), t/5]
range=[0, 31.4], color=magenta


5. 二维向量场

[y, -x]
range=[-5, 5], step=0.5


全局配置规范

通过插件设置面板，可针对如下维度进行系统级设定：

空间布局与几何尺寸：包括但不限于默认容器宽度、预设高度以及移动终端触发阈值之界定。

视觉审美属性：涵盖全局绘图主题、背景透光率、默认曲线色值、坐标网格色彩及文本字号标定。

计算性能控制：旨在通过调整采样点总数（渲染质量）以实现视觉平滑度与计算资源占用之间的最优平衡。

缺省定义域：规定在未明确指派范围参数时系统默认引用数学区间。
